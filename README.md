# Rift.GG

한국 서버 LoL 소환사를 검색하고 프로필과 솔로·자유 랭크를 확인하는 서비스입니다. React, TypeScript, Vite, Tailwind CSS v4, Supabase를 사용합니다.

```powershell
npm install
npm run dev
```

실제 Riot 데이터 조회에 필요한 환경변수와 Supabase 연결 방법은 [개발·배포 절차](docs/common/development.md)에서 확인하세요. 후속 개발을 위한 공통 문서와 기능별 문서는 [문서 목차](docs/README.md)에 정리했습니다.
